# 巡演布景坐标换算台

纯前端的二维**相似变换**换算台：定位员录入设计侧基准点 A、B，现场侧对应点
A′、B′，以及若干具名设计落点，页面立即给出每个落点的现场坐标，同时展示
统一缩放率、旋转角与复核量。换算完成后，还可在同一页面录入**现场复测坐标**，
设置一项全局允许偏差，逐点核对实际放样是否处于容差内。

坐标单位固定为 **毫米**；坐标系 **x 向右、y 向上**，**逆时针角为正**。

## 变换模型（唯一、不含拉伸/镜像）

由两对基准只能确定平移 + 统一缩放 + 旋转：

- 有向向量：d = B − A，d′ = B′ − A′
- 统一缩放率：`s = |d′| / |d|`（恒为正，因此不会镜像）
- 旋转角：`θ = atan2(d′) − atan2(d)`，规范到 **(−180°, +180°]**
  （恰为 −180° 时表示为 +180°，保证唯一）
- 落点换算：`q = A′ + s·R(θ)·(p − A)`

不存在非等比缩放（x/y 同一缩放率），也不存在翻转；角度取两条有向基准
向量的 atan2 角差，方向不会写反。

## 精度与舍入

- 内部计算保留 `number` 全部精度，不做中途截断。
- 只有现场坐标**展示**时保留两位小数，采用
  **“恰好半个最小单位向绝对值增大方向取整”**（half away from zero），
  对十进制半点（如 `1.005`、`-2.345`）按十进制语义处理。
- 复核量：把现场坐标反算回设计侧，显示反算坐标以及与原设计点的距离
  （闭合差），并对 A→A′、B→B′ 做基准闭合复核。

## 整批拒绝规则

以下任一情况出现时，**整批拒绝**：不生成或保留任何旧结果，错误面板逐条
指出问题字段/原因：

- 任一字段为空，或不是有限数（`abc`、`Infinity`、`NaN`、`1e999` 等）；
- 任一侧两个基准点重合（A=B 或 A′=B′）；
- 缩放率不是有限正数；
- 输入虽为有限数，但数值过大，使中间运算（缩放、旋转、平移相加、复核）
  或展示精度放大（毫米 ×100、缩放率 ×10⁶、闭合差 ×10⁹）溢出为
  `Infinity/NaN`——即使数学结果本身有限（例如恒等换算下落点 `1e308`），
  也整批拒绝并提示「超出数值范围」，不会显示 Infinity、空缺符号或无效复核量；
- 没有具名落点，或落点名称为空。

落点名称仅作展示标签，**允许重名**：两个同名落点都会保留并分别换算。
首次合法输入后显示全部落点与复核量；任何合法坐标发生变化都立即重算并
**完整替换**旧结果。

## 现场复测核对（可选，不影响换算）

换算成功后，结果区下方出现“现场复测核对”面板：设置一项**全局允许偏差**
（非负毫米数），为每个既有具名落点成对录入现场复测 x/y，页面立即核对。

- 偏差由相似变换产生的**全精度现场坐标**计算，不使用两位小数的展示舍入值：
  - 纵向差：实测点相对期望现场点，沿现场基准 A′→B′ 方向的分量（同向为正）；
  - 横向差：沿 A′→B′ 逆时针转 90°（线路左侧）方向的分量为正；
  - 直线偏差：实测点与全精度期望现场点的距离；
  - 核对状态：**直线偏差 ≤ 允许偏差 → 合格**，大于 → 超差；恰好位于边界也合格。
- 页面展示仍按现有规则：坐标/偏差显示到 0.01 mm（半点向绝对值增大方向取整），
  但合格判定始终基于全精度值（测试以旋转 + 缩放数据证明，误用展示期望 100.00
  会得到相反结论）。
- 每行复测 x/y **均为空 → 未录入**，不影响换算，也不需要允许偏差；
  成对有限数录入后立即刷新偏差与状态。
- 以下情况把**对应行**标记为“输入无效”，并在相关控件附近说明原因；
  换算结果、基准复核与其他有效行继续保留，修正后即时恢复核对：
  - 只填写一个坐标，或任一坐标为非有限数（`abc`、`Infinity`、`NaN`、`1e999`）；
  - 复测坐标虽为有限极大值，但合成偏差（纵向差/横向差/直线偏差）放大到展示
    精度后溢出（斜向时合成量可达分量的 √2 倍）——整行无法核对，绝不出现
    “超差”结论却空缺偏差列的混搭；
  - 已有复测录入但允许偏差为空；允许偏差为非有限数或负数（即使尚未录入复测也立即提示）。
- 复测数据按落点行的**内部标识**关联，动态增删、同名落点都不会串行；
  删除一行后其复测数据一并消失，不会串到其他行。
- 完全不使用复测功能时，页面行为与无此功能时完全一致。

## 本地开发

```bash
npm ci
npm run dev          # http://localhost:5173
```

## 测试

```bash
npm run test:unit    # Vitest：求解、舍入、无效边界 + React 交互
npm run build        # tsc 类型检查 + Vite 构建
npm run test:e2e     # Playwright（自动启动 vite preview）
npm run verify       # 单测 + 构建 + 端到端 一次性验收
```

端到端用例覆盖：初始空态、+90°/−90° 旋转方向、±180° 接缝取短角、
缩放率展示、半点舍入、清空字段后整批拒绝与补回后替换、非有限数拒绝、
基准重合拒绝、同名落点分别换算、极大有限值溢出拒绝、动态增删落点；
以及现场复测：未使用时行为不变、旋转+缩放下用全精度而非舍入坐标判定
（两笔数据若误用展示期望 100.00 结论相反）、合格改超差即时更新而其余行与
换算坐标不变、3-4-5 边界合格与横/纵向差符号、单边/非有限坐标与
空/非有限/负允许偏差的行级无效提示与即时恢复、动态增删及同名落点按
内部标识关联（删除不串行）、有限极大复测坐标使合成偏差不可展示时整行无效。

## Docker Compose

Web 前端构建为 nginx 静态镜像；宿主端口由 `WEB_PORT` 覆盖
（默认 8080）：

```bash
docker compose up -d --build web
# 自定义宿主端口：
WEB_PORT=9000 docker compose up -d --build web
```

一次性验收服务（单测 → 构建 → Playwright 指向 Web 容器）：

```bash
docker compose --profile verify run --rm --build verify
```

`verify` 通过 `E2E_BASE_URL=http://web:80` 对正在运行的 Web 服务做端到端
验证，结束后容器退出（成功退出码 0）。

## 目录结构

```
src/
  lib/geometry.ts   相似变换求解、角度规范化、输入解析、复测核对（纯函数）
  lib/format.ts     展示层舍入（half away from zero）与格式化
  App.tsx           交互式数值表单、整批拒绝、结果/复核面板、现场复测核对
tests/
  unit/             Vitest（geometry / format / App / 复测核对）
  e2e/              Playwright 页面交互
```
